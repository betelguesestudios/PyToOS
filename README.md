Download the latest release [here](https://github.com/betelguesestudios/PyToOS/releases/latest)

## How to run

1: Download the latest release [here](https://github.com/betelguesestudios/PyToOS/releases/latest)

2: Extract the zip to wherever

3: Run testall.bat by either double clicking the file or cding into the directory you extracted the zip and running testall.bat

4: This will delete all previous build files, and compile the main.py file into a .bin and you can open it with qemu by selecting a path
